SELLZA public assets

Copy all files in this folder into your project’s client/public/ folder.
The app icons use SELLZA blue (#2563EB) and a simple receipt/check mark motif.
site.webmanifest configures the install name, colours, start URL and icons.
robots.txt and sitemap.xml currently reference only the public homepage.
No service worker is included because offline caching is not currently required.
Do not add a Netlify _redirects file to this Vercel project.
